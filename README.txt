# READ-UP Website

READ-UP: Reading Enhancement and Development through Understanding and Practice
Labangal National High School

## Files
- index.html — main website
- style.css — design and responsive layout

## How to use
1. Extract the ZIP file.
2. Open `index.html` in a browser to preview the website.
3. Replace the sample reading passages and activities in `index.html` with your actual READ-UP materials.
4. For PDFs, upload them to Google Drive and replace the placeholder links.
5. For online assessments, create Google Forms and replace the sample assessment button/link with your Form URL.
6. Publish the folder using a static hosting service such as GitHub Pages, Netlify, or another school-approved web host.

## Important
The sample progress tracker uses the learner's browser only (localStorage). It is not a secure student information system. For real learner records, use a school-approved platform and follow applicable DepEd privacy and data-protection procedures.
